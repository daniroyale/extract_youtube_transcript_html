# extract_youtube_transcript_html
extract_youtube_transcript_html

Usando skills, Obten la transcripcion del video de youtube LINK salvalo en la raiz del workspace. Luego toma el archivo corrige la gramatica y puntuacion y dividelo en parrafos de 7500 caracteres y salvalo a un archivo de texto. Luego toma el resultado y crea un archivo html en un formato moderno y compatible con el HTML custom box de Wordpress. Salva el html final en la raiz del workspace.
